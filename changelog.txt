Version: 2.3.0
Date: 01/25/2026
    Info: Added tier-specific enable/disable toggles
    Features:
    - Added individual toggle settings for each conversion tier (9 total)
    - Players can now enable/disable specific science conversions:
      * Tier 1: Red ↔ Green
      * Tier 2: Green ↔ Blue
      * Tier 3: Blue ↔ Purple
      * Tier 4: Purple ↔ Yellow
      * Tier 5: White ↔ Orange
      * Tier 6: White ↔ Pink
      * Tier 7: White ↔ Lime
      * Tier 8: White ↔ Dark Blue
      * Tier 9: White ↔ Black
    - Disabled tiers hide their recipes and technologies
    - All tiers enabled by default for backward compatibility
    - Perfect for challenge runs or restricting specific conversions
--------------------------------------------------------------------------
Version: 2.2.0
Date: 01/25/2026
    Info: Added customizable mod settings
    Features:
    - Added toggle for linear conversion scaling (enable/disable progressive ratios)
    - Added setting to customize base upgrade ratio (default: 10)
    - Added setting to customize base downgrade ratio (default: 1)
    - Added setting to customize product amount multiplier (default: 1)
    - Added setting to customize conversion time in seconds (default: 10)
    - All settings are startup settings and require game restart to apply
    - Settings accessible via Main Menu → Settings → Mod Settings → Startup tab
