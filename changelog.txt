Version: 2.5.0
Date: 2026-01-31
  Major Features:
    - Base Factorio compatibility - mod now works without Space Age expansion!
  Changes:
    - Made Space Age an optional dependency
    - Space Age science conversions (tiers 5-9) only load when expansion is installed
    - Base game conversions (tiers 1-4) always available
    - Updated mod description to reflect dual compatibility
  Info:
    - Base Factorio: 4 technologies unlocking 8 recipes (Red↔Green, Green↔Blue, Blue↔Purple, Purple↔Yellow)
    - With Space Age: All 9 technologies unlocking 18 recipes (includes planet sciences)
    - No configuration needed - automatically detects installed content
    - All existing settings work with both versions

Version: 2.4.0
Date: 2026-01-25
  Major Features:
    - Added bidirectional conversion toggles - control upgrades and downgrades separately
    - Added pollution multiplier - make conversions clean (0) or dirty (10x)
  Changes:
    - New setting: "Enable Upgrade Conversions" - toggle all lower→higher tier conversions
    - New setting: "Enable Downgrade Conversions" - toggle all higher→lower tier conversions
    - New setting: "Pollution Multiplier" - control pollution from conversions (range: 0.0-10.0)
  Info:
    - Perfect for challenge runs (upgrades only, downgrades only, eco-friendly, pollution challenge)
    - Works in combination with tier-specific toggles for maximum control
    - All settings enabled by default for backward compatibility
