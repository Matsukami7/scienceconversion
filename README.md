After researching the requiremnts in the game, you can turn one science into another, up and down a tier. Allowing you to create new and unique factories!

## Features

- Convert science packs up and down tiers
- Fully customizable conversion ratios via mod settings
- Toggle between linear scaling and uniform conversion rates
- Adjust conversion times and product amounts
- Compatible with Factorio 2.0 and Space Age content

## Mod Settings

Version 2.2.0 introduces customizable settings! Access them via:
**Main Menu → Settings → Mod Settings → Startup tab**

Available settings:
- **Linear Conversion Scaling**: Toggle between progressive ratios (10, 20, 30, 50, 100) or uniform ratios
- **Base Upgrade Ratio**: Set how many science packs are needed to upgrade (default: 10)
- **Base Downgrade Ratio**: Set how many science packs are needed to downgrade (default: 1)
- **Product Amount Multiplier**: Multiply the output of conversions (default: 1)
- **Conversion Time**: Adjust how long each conversion takes in seconds (default: 10)

*Note: These are startup settings and require restarting your game to apply changes.*
